About Me

Born and raised in Hong Kong, now studying Computer Science (with a Math minor) at the University of Oregon. I build things that work — backends, APIs, infrastructure — and I care about who they work for.

That's what drew me to elderly tech: my ElderCare Connect project started from watching how frustrating most apps are for older adults. I wanted to build something that felt invisible — so simple that the tech gets out of the way.

Outside of class, I run my own self-hosted infrastructure on a Hetzner VPS — reverse proxies, workflow automation, AI agent pipelines — because the best way to learn distributed systems is to operate one yourself.

Projects

ElderCare Connect — Elder-Care & Family Monitoring PWA

Problem: Most health apps assume tech-literate users — leaving elderly adults and their worried families with no practical way to stay connected around daily care.

What I built: A two-sided web app where elderly users complete medication and wellness tasks through a dementia-friendly UI (high-contrast, large tap targets, single-action screens), while family members remotely monitor progress in real time. Implemented JWT auth with persistent device trust so elders never need to re-login, and role-based views that swap the entire UX between Elder and Family modes. Led a 4-person team as PM & Scrum Lead — owned product scope, UX decisions, and sprint planning from day one.

React · Node.js · JWT Auth · MongoDB · Docker Compose

Elderly Companion — AI Cognitive Health Tracker

Problem: Caregivers notice subtle cognitive changes day-to-day but have no structured way to track them or know when to escalate.

What I built: A full-stack app where caregivers log daily observations (memory, orientation, mood) and receive AI-generated risk assessments that analyze multi-day trends. The Flask + MongoDB backend exposes a clean REST API; the OpenAI integration uses structured JSON parsing with engineered prompts to produce consistent, machine-readable outputs. Built graceful degradation so the entire app remains fully functional when the AI service is unavailable — no crashes, just a fallback message. One-command Docker Compose deployment.

Flask · MongoDB · REST API · OpenAI API · Docker Compose · Gunicorn

AI Resume Pipeline — Multi-Agent Workflow Automation

Problem: Tailoring a resume per job posting takes 30–60 minutes. At scale, that’s unsustainable.

What I built: A Telegram-triggered pipeline that generates ATS-optimized, role-specific resumes in under 60 seconds. The 4-phase workflow — job ad parsing → adversarial debate between Claude Opus and GPT → resume generation with python-docx → automated critique loop — runs entirely on my self-hosted n8n instance. One Telegram message in, a polished .docx out.

n8n · Python · Claude API · OpenAI API · Docker · Telegram Bot

Syllabify — AI-Powered Academic Organizer

Problem: Every semester, students manually copy deadlines from PDFs into their calendars — tedious, error-prone, and nobody actually keeps it updated.

What I built: A platform that ingests course syllabi via an NLP pipeline, extracts assignments, exams, and office hours, then auto-syncs everything to Google Calendar. Upload a PDF, get a structured semester schedule with zero manual entry.

React · Node.js · PostgreSQL · Python NLP · Google Calendar API
